# 🚖 Uber Bookings Analysis Dashboard

## 📊 Project Overview

The **Uber Bookings Analysis Dashboard** is a data visualization project created using **Microsoft Power BI**.
The goal of this project is to analyze Uber ride booking data and generate insights about ride demand, revenue, trip distance, and booking patterns.

The dashboard provides interactive visualizations to help understand booking trends and business performance.

---

## 🎯 Objectives

* Analyze Uber ride booking data
* Identify booking trends and ride patterns
* Track revenue and trip performance
* Visualize key business metrics using dashboards
* Provide insights to support data-driven decisions

---

## 🛠 Tools & Technologies Used

* **Power BI**
* Data Cleaning
* Data Visualization
* Dashboard Design
* Data Analysis

---

## 📂 Dataset Information

The dataset contains information related to Uber rides such as:

* Booking ID
* Date and Time
* Pickup Location
* Drop Location
* Trip Distance
* Fare Amount
* Payment Type
* Ride Status

---

## 📈 Dashboard Features

The Power BI dashboard includes the following insights:

* Total Bookings
* Total Revenue
* Trip Distance Analysis
* Booking Trends Over Time
* Location-based Ride Analysis
* Payment Method Distribution

---

## 📊 Key Performance Indicators (KPIs)

The dashboard highlights important metrics such as:

* Total Trips
* Average Trip Distance
* Total Revenue Generated
* Most Frequent Pickup Locations
* Ride Distribution by Payment Type
